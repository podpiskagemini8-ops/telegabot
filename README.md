# 🤖 Telegram-бот Анонимных Вопросов с Админ-панелью и Деанонимизацией

Полнофункциональный и современный Telegram-бот анонимных вопросов, написанный на **Python 3** с использованием библиотеки **aiogram 3** и асинхронной базы данных **SQLite (aiosqlite)**.

---

## 🌟 Основные возможности

### 👤 Для обычных пользователей:
1. **Персональная ссылка**: Получение персональной ссылки вида `https://t.me/BotUsername?start=USER_ID` для размещения в Telegram Stories, шапке профиля Instagram, VK, TikTok или на других ресурсах.
2. **Анонимные сообщения**: Любой желающий может написать анонимное сообщение (поддерживаются текст, фото, голосовые сообщения, видео, видео-кружочки, стикеры, документы и GIF).
3. **Анонимный ответ**: Получатель может ответить на анонимное сообщение прямо через бота.
4. **Статистика**: Просмотр количества полученных и отправленных сообщений.

### 👑 Для Администраторов (Указанных Telegram ID):
1. **🕵️‍♂️ Функция «Узнать кто это» (Деанонимизация)**:
   - Под каждым входящим анонимным сообщением у администратора отображается кнопка `🕵️‍♂️ Узнать кто это`.
   - При нажатии бот моментально присылает карточку с полными данными об авторе сообщения:
     - **Telegram ID**
     - **Имя и Фамилия**
     - **Юзернейм** (`@username`)
     - **Прямая ссылка на профиль** (`tg://user?id=...`)
     - **Дата и время отправки**
     - **Кнопка быстрой блокировки** (бана) нарушителя.
2. **⚡ Админ-панель (`/admin` или кнопка в меню)**:
   - 📊 **Детальная статистика**: общее количество пользователей, новые за сегодня, счетчик сообщений.
   - 📢 **Массовая рассылка**: отправка сообщений (с фото, видео, кнопками) всем пользователям бота с защитой от лимитов.
   - 📜 **Логи сообщений**: просмотр последних сообщений с указанием того, кто кому и что писал.
   - 👥 **Управление админами**: добавление доверенных ID через интерфейс бота.
   - 🚫 **Бан-система**: блокировка и разблокировка пользователей по ID.

## 🚀 Инструкция по установке и запуску

### 1. Получение токена бота
1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям: введите название бота и юзернейм (должен заканчиваться на `bot`, например `MyAnonAskBot`).
3. Скопируйте полученный **API Token** (выглядит как `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### 2. Как узнать свой Telegram ID
1. Откройте бота [@userinfobot](https://t.me/userinfobot) в Telegram.
2. Он пришлет ваш цифровой **Id** (например, `987654321`).
3. *(Или после первого запуска бота напишите команду `/id`).*

### 3. Настройка конфигурации (`.env`)
Откройте файл `.env` в корне проекта и заполните параметры:

```env
# Вставьте токен вашего бота
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Укажите Telegram ID администраторов через запятую
ADMIN_IDS=987654321,123456789

# Путь к БД (по умолчанию database.sqlite3)
DB_PATH=database.sqlite3
```

### 4. Установка зависимостей и запуск

Установите необходимые библиотеки (если еще не установлены):
```bash
pip install -r requirements.txt
```

Запустите бота:
```bash
python main.py
```

│   ├── __init__.py
│   └── db.py              # Асинхронные методы работы с SQLite (aiosqlite)

│   ├── __init__.py

├── middlewares/

├── requirements.txt       # Список зависимостей Python
